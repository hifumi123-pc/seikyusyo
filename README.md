# 請求書作成ツール 📄

日本の正式な請求書（インボイス）を簡単に作成・管理できるWebアプリケーションです。

## 🎯 主な機能

### インボイス制度対応
- **T番号（適格請求書発行者番号）** の記載対応
- - 日本の税制に準拠した正式な請求書形式
 
  - ### 柔軟な明細管理
  - - **動的に行を追加・削除** できる明細セクション
    - - 品目名、数量、単価を自由に入力
      - - リアルタイムで合計金額を自動計算
       
        - ### 複数税率対応
        - - **10%（標準税率）** と **8%（軽減税率）** の自動計算
          - - **非課税項目** にも対応
            - - 税率ごとの詳細な集計表示
             
              - ### PDF出力対応
              - - ブラウザの **プリント機能でPDF化**
                - - 高品質な印刷レイアウト
                  - - フォーム入力欄は非表示で、完成した請求書のみを出力
                   
                    - ## 🚀 使い方
                   
                    - ### 基本的な使用方法
                   
                    - 1. **サイトにアクセス**
                      2.    ```
                               https://hifumi123-pc.github.io/seikyusyo/
                               ```

                            2. **請求書情報を入力**
                            3.    - 発行者情報（会社名、住所、T番号など）
                                  -    - 請求先情報（顧客名、住所、連絡先など）
                                       -    - 請求日、納期などの日付
                                        
                                            - 3. **明細を追加**
                                              4.    - 「明細を追加」ボタンで新しい行を追加
                                                    -    - 品目名、数量、単価、税率を入力
                                                         -    - 自動で小計と税額が計算されます
                                                          
                                                              - 4. **確認して保存/印刷**
                                                                5.    - プレビューで全体を確認
                                                                      -    - ブラウザのプリント機能（Ctrl+P / Cmd+P）でPDF化
                                                                           -    - または直接印刷
